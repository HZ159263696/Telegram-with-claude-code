# Claude Bridge — 安卓 App 使用说明

太子手搓的 Android WebView App，**只是手机端的"遥控器"**——电脑上的 bridge / dashboard 服务必须开着，APK 只是把控制面板套个壳搬到手机上。

## 安装

1. 拿到 `ClaudeBridge.apk`（在 `D:\AI\claudecode-telegram-main\dist\` 里）
2. 用 QQ / 微信 / U盘 / 数据线传到手机
3. 手机点开 APK，允许"未知来源安装"
4. 装好后桌面图标叫 **Claude Bridge**

> 首次安装如果被拦：设置 → 安全 → 允许此来源安装应用

## 首次使用

1. **电脑这边先把控制面板跑起来**：双击桌面的 `Claude Bridge2.1.exe`，或者跑 `start.sh`
2. **手机打开 Claude Bridge**，会跳到设置页让你填地址，两种选一种：

### A. 局域网（手机和电脑同 WiFi，最快）

填：`http://192.168.124.17:8888`

> 这是太子检测到的当前电脑局域网 IP。如果以后路由器换了/IP 变了，按 **左上角菜单 → 设置** 改即可。
> 不知道电脑 IP 时：Windows 命令行 `ipconfig` 查 IPv4 地址。

### B. 公网 ngrok（外网也能用，慢一点）

填：`https://你的ngrok子域.ngrok-free.app`

> 这个地址在 `start.sh` 启动时会输出在控制台。或者去 dashboard 控制台 → "Tunnel" 标签看当前公网地址。

3. 点 **保存并打开** → 控制面板就出来了

## 用法

| 操作 | 效果 |
|------|------|
| 下拉刷新 | 重载控制面板 |
| 双指捏合 | 缩放页面 |
| 右上角菜单（⋮） | 重新加载 / 回首页 / 改设置 |
| 返回键 | 网页内回退 / 退出 |

控制面板里所有功能（模型切换、Bot 管理、SSE 实时日志、Token 统计、Webhook 配置……）原汁原味，跟桌面 exe 完全一样。

## 已知限制

- **必须电脑开着** —— APK 只是个客户端，没有电脑跑 bridge 就连不上
- **不支持推送通知** —— 想要消息提醒还是用 Telegram bot
- **debug 签名** —— 没花钱买证书签名，第一次装时 Android 会提示"未知开发者"，正常通过即可

## 改了 URL 想换地址？

App 内 **菜单 → 设置** 重新填新地址保存即可，不用重装。
